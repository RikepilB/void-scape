The decision point. Separates transcription spend from vision-token cost and shows exactly which gates apply.

// Agent-first design

Built for agents. Legible for humans.

One stable contract: JSON envelopes, deterministic exit codes, and gates an agent must check before it acts.

--json / --envelope

Guided commands emit JSON; the engine emits {ok,data,error,meta}. Machines parse; humans read.

exit codes 0–6

Success, usage, input, approval required, dependency, and operation failure are distinct, deterministic values.

--tier visual|audio|both

Price and extract only the channels the task needs — frames, transcript, or both.

--start / --end

Scope work to a time window. Output timestamps stay pinned to the source timeline.

--allow-cloud

A capability for one invocation, not a setting. Cloud transcription is rejected before upload without it.

--allow-model-download

A first local Whisper model download needs its own explicit, per-run consent.

manifest --compact

Agents introspect commands, flags, and protocol version at runtime. No docs scraping needed.

[MM:SS] · [image N] · [article N] · [entry N]

Citation contracts are part of the output. Agents quote moments, frames, articles, and feed entries—not vibes.

--backend captions

Free transcription paths first: existing captions, sidecars, or local Whisper. Paid backends are opt-in.

01 / Available now

Read the sources you already have.

A local-first pipeline for media, article, and feed evidence with visible approval gates.

  • Local video and recordings

    Analyze demos, meetings, tutorials, screen captures, and personal archives from a local file.

  • Image and carousel reading

    Read one JPG, PNG, or WebP—or one local folder in natural filename order—through the same inspect → preview → read path. Originals stay untouched.

  • Public video URLs

    Bring a supported video URL into the same inspect → preview → read path, including individual YouTube links.

  • Audio, captions, and transcript sidecars

    Use available captions, transcribe locally, or reuse a matching SRT, VTT, or text sidecar without generating it again.

  • Scoped visual reads

    Choose visual, audio, or both; limit work to a time window; and keep output timestamps pinned to the source timeline.

  • Agent-native protocol

    Machine-readable envelopes, stable exit codes, and a discovery manifest let an agent plan and handle failures explicitly.

  • Articles and RSS/Atom

    Read local Markdown, HTML, text, and feeds. Public article fetches require a separate, explicit approval.

  • On-demand observe capture

    Create a chosen screenshot or short silent clip on supported hosts, then pass the local file through inspect → preview → read.

  • One inspectable evidence bundle

    Give an agent selected frames, timestamped text, and a source manifest together instead of asking it to infer a video from its title.

Questions worth answering before you hand media to an agent.

Voidscape makes the boundary visible: what stays local, what costs, and what exists today.

Does Voidscape upload my media?

Not by default. Local files, sidecar transcripts, and local transcription stay on your machine. Any cloud transcription route needs a current --allow-cloud approval; a first local model download needs its own --allow-model-download.

What files does “read” create?

A work folder containing selected frames, a transcript when requested, and a manifest that maps frames to timestamps. An agent can turn those artifacts into a Markdown note; the CLI does not pretend to write a semantic note itself.

When should I inspect, preview, or read?

Inspect is free source discovery. Preview is the cost and privacy decision. Read only follows once the path is acceptable and prepares the evidence an agent needs.

Can I use it for Instagram research or voice notes?

Audio-only reads use the installed CLI. Instagram support is a repository-only URL helper and user-observed development workflow, not an installed command.

What if the media needs my login?

Public URLs are the baseline. For media you are permitted to access, the CLI can optionally use a local cookie export while a browser-connected agent works from tabs only after your site approval. Voidscape never extracts your browser credentials, and first-party account connections are future work.
