Guide / a grounded media story

From “what is in this?” to evidence you can inspect.

Transcription is one channel, not the final result. Voidscape prepares the visual and audio evidence an agent needs, while making three small decisions visible so you stay in control of what happens to your media.

Before you begin

Choose one file or public URL you are allowed to use.

A meeting recording, screen capture, voice memo, demo, or supported public video URL is enough. Start with the key-free demo fixture if you want to see the flow without an account, API key, or personal media.

Available today. Local video and audio, supported public URLs, captions, local transcription, frames, timestamped transcripts, and a manifest that connects evidence to the original timeline.
01 / Inspect

Look before you process.

Inspect reads source facts: duration, resolution, audio, captions, and local sidecars. Nothing is uploaded or transformed. You learn what is actually available before choosing a path.

python skill/scripts/voidscape.py inspect "clip.mp4"
Already have a transcript? Put a matching .srt, .vtt, or .txt file beside local media. Voidscape can reuse that sidecar locally; timestamped SRT/VTT is required when reading only a time window.
02 / Preview

See the tradeoff before you approve it.

Preview explains the frame plan, transcription route, expected dependencies, and API-equivalent vision estimate. If audio would leave your computer or a local model must download for the first time, Voidscape stops for a separate explicit approval.

python skill/scripts/voidscape.py preview "clip.mp4" --tier both --backend captions
Your decision point. --allow-cloud and --allow-model-download are never implied by having a key, a browser session, or an earlier run.
03 / Read

Create only the evidence you chose.

After the preview is acceptable, read selects frames and creates a transcript and manifest in a work folder. The output is deliberately inspectable: you can open the files, check the moments, and keep or delete the folder when you are done.

python skill/scripts/voidscape.py read "clip.mp4" --tier both --backend captions --workdir out
Then / Ask

Give the artifacts to an agent, not just a title.

Open frames/, transcript.txt, and manifest.json. Ask for a summary, decision note, or answer to a concrete question—and ask the agent to cite moments as [MM:SS]. The CLI prepares evidence; an agent authors the interpretation.

Good prompt: “What decision was made around 05:12? Quote the transcript and cite the timestamp.”
Coming soon / planning lock

Useful directions, clearly not shipped.

These are planning-lock items, not commands or product promises. Each needs its own privacy, platform, and implementation review before it becomes available.

Private YouTube queue capture

Designed around a user-owned private playlist and the official YouTube Data API. The current CLI can read an individual permitted URL; queue capture is coming soon.

Images, carousels, articles, RSS, and saved posts

Planned expansions beyond the present media engine. They are not current installed inputs.

More source adapters and agent/MCP packaging

Possible ways to make approved evidence easier to collect and use across environments. Not a current public API surface.

Hosted service, browser extension, and unattended workflows

Exploration only—not a promise. These would require separate product design, legal review, account controls, and consent rules.
