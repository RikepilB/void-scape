Host and authentication boundary#

Remote control continues work on a host; it does not move that host's files, browser profile, or CLI credentials to the phone. A browser connection may view a page the user is permitted to access, but yt-dlp remains separately authenticated. For allowed account-scoped media, the user may set a site-scoped Netscape cookie file through READ_VIDEO_YTDLP_COOKIES. Voidscape never discovers, exports, or reads cookies from a browser profile.

See authenticated sources and the browser/CLI evidence matrix.
