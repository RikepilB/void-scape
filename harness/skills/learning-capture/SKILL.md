# Learning Capture

Extract only durable, evidenced lessons: the trigger, context, decision, and validation. Keep
project-specific facts local unless they generalize across projects.

Produce a proposal first. Do not modify skills, agent settings, memory, or a knowledge base
without explicit approval for that target.
